# FitTrack — тренировки и питание

Мобильное приложение (React Native + Expo) для тренажёрного зала: программы с прогрессией
нагрузок, активная тренировка с таймером отдыха, дневник, прогресс и трекер КБЖУ.
Работает **полностью локально на устройстве** — без сервера, без интернета и без подписок.

**Дизайн:** Dark Premium — фон `#0e0e11`, акцент `#d6ff4b`, шрифт Manrope, высокий контраст.

## Возможности

- **Онбординг (3 шага):** цель → уровень → дни недели + пол/возраст/вес/рост.
  Автоматически назначается программа и рассчитывается норма КБЖУ (Миффлин–Сан Жеор + цель).
- **4 готовые программы:** Full Body 3×, PPL 6×, Upper/Lower 4×, Бро-сплит 5× —
  с RPE, отдыхом и автопрогрессией (+2.5 кг базовые / +1.25 кг изолирующие, вес растёт
  только при выполнении целевых повторений).
- **Свободная тренировка:** карточки групп мышц, рекомендованные упражнения,
  веса подтягиваются из истории. Не ломает цикл программы.
- **Активная тренировка:** ввод подхода за 3–5 секунд (вес + повторы + OK),
  таймер отдыха с ±15 сек и вибрацией, прогресс-бар, добавление упражнений на лету.
- **Библиотека:** 70+ упражнений с техникой (статичный текст), поиск и фильтр по группе мышц.
- **Дневник и Прогресс:** история по датам, тоннаж, графики весов, личные рекорды.
- **Питание:** кольцо калорий, плитки Б/Ж/У/клетчатка, лента приёмов,
  база 1000+ продуктов (русские блюда в приоритете), ручной ввод через поиск,
  расчёт нормы КБЖУ по формуле TDEE, отчёты за неделю/месяц с экспортом PDF.
- **Офлайн и бесплатно:** все данные хранятся локально (SQLite). Интернет не нужен.

## Навигация — 5 вкладок

`[Главная] [Программа] [Дневник] [Прогресс] [Питание]`

## Структура

```
src/
  app/            экраны (expo-router): 5 вкладок, онбординг, тренировка, еда, отчёты
  components/     CalorieRing, RestTimer, LineChart, UI-примитивы
  data/           упражнения, программы, база продуктов
  db/             SQLite: exercises, workouts, sets, user_progress, nutrition_log, food_database
  lib/            TDEE/КБЖУ, прогрессия, типы
  store/          профиль (AsyncStorage) и активная тренировка
public/           PWA: manifest.json, sw.js (офлайн), иконки
scripts/          pwa-postbuild.mjs — вставляет PWA-теги в собранный index.html
```

## Запуск

### Вариант 1. Разработка (Expo Go)

```bash
npm install
npx expo start
```
Открой QR-код в Expo Go (iOS/Android).

### Вариант 2. Установка на телефон как приложение (PWA)

Бесплатная установка с иконкой на домашний экран iPhone/Android — **без App Store
и без аккаунта разработчика**. Пошагово: [QUICKSTART.md](./QUICKSTART.md).

Коротко:
```bash
npm run build:web        # собирает PWA в папку dist/
```
Затем выложи содержимое `dist/` на любой бесплатный HTTPS-хостинг
(Netlify / Cloudflare Pages / Vercel / GitHub Pages) и открой ссылку в Safari →
«Поделиться» → «На экран Домой».

## Схема БД (SQLite)

`exercises` · `workouts` · `sets` · `user_progress` (личные рекорды) · `nutrition_log` ·
`food_database` (1000+ позиций, сидируется при первом запуске). Настройки пользователя —
в AsyncStorage (`user_settings`). Программы тренировок — статические данные в `src/data/programs.ts`.

На вебе (PWA) та же база работает через OPFS-бэкенд wa-sqlite — данные сохраняются
между запусками прямо в браузере/приложении.
