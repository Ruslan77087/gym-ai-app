# GymAI — тренировки с AI-тренером и трекером питания

Мобильное приложение (React Native + Expo) для тренажёрного зала: программы с прогрессией
нагрузок, активная тренировка с таймером отдыха, AI-трекер калорий с распознаванием еды
по фото (Claude Vision) и единый AI-тренер/нутрициолог на общем контексте.

**Дизайн:** Dark Premium — фон `#0e0e11`, акцент `#d6ff4b`, шрифт Manrope, высокий контраст.

## Возможности

- **Онбординг (3 шага):** цель → уровень → дни недели + пол/возраст/вес/рост.
  Автоматически назначается программа и рассчитывается норма КБЖУ (Миффлин–Сан Жеор + цель).
- **4 готовые программы:** Full Body 3×, PPL 6×, Upper/Lower 4×, Бро-сплит 5× —
  с RPE, отдыхом и автопрогрессией (+2.5 кг базовые / +1.25 кг изолирующие, вес растёт
  только при выполнении целевых повторений).
- **Свободная тренировка:** карточки групп мышц, рекомендованные упражнения,
  веса подтягиваются из истории. Не ломает цикл программы.
- **Активная тренировка:** ввод подхода за 3–5 секунд (вес + повторы + OK),
  таймер отдыха с ±15 сек и вибрацией, прогресс-бар, добавление упражнений на лету.
- **Библиотека:** 70+ упражнений с техникой, поиск и фильтр по группе мышц.
- **Дневник и Прогресс:** история по датам, тоннаж, графики весов, личные рекорды.
- **Питание:** кольцо калорий, плитки Б/Ж/У/клетчатка, лента приёмов,
  база 1000+ продуктов (русские блюда в приоритете), фото-распознавание (Claude Vision),
  голос/текст через AI-парсер, отчёты за неделю/месяц с экспортом PDF.
- **AI-тренер:** один чат для тренировок и питания. Видит программу, сегодняшнюю
  тренировку, рацион и норму КБЖУ, личные рекорды. Отвечает только по-русски.
- **Офлайн:** программы, дневник, прогресс и база продуктов работают без интернета
  (SQLite). Интернет нужен только для фото еды и чата с AI.

## Структура

```
src/
  app/            экраны (expo-router): 6 вкладок, онбординг, тренировка, еда, отчёты
  components/     CalorieRing, RestTimer, LineChart, ChatView, UI-примитивы
  data/           упражнения, программы, база продуктов
  db/             SQLite: exercises, workouts, sets, user_progress, nutrition_log, food_database
  lib/            TDEE/КБЖУ, прогрессия, AI-клиент, типы
  store/          профиль (AsyncStorage) и активная тренировка
server/           Node-прокси к Claude API (ключ живёт только здесь)
```

## Запуск

### 1. AI-сервер

```bash
cd server
npm install
export ANTHROPIC_API_KEY=sk-ant-...   # ключ хранится только на сервере
npm start                              # http://localhost:3000
```

Модель: `claude-sonnet-4-6` (чат и Vision). Эндпоинты: `/api/chat`, `/api/food/photo`,
`/api/food/parse`, `/api/meal-plan`, `/health`.

### 2. Приложение

```bash
npm install
# адрес AI-сервера (для телефона укажи IP компьютера в локальной сети):
export EXPO_PUBLIC_API_URL=http://192.168.x.x:3000
npx expo start
```

Открой в Expo Go (iOS/Android) или собери dev-клиент (`npx expo run:android` / `run:ios` —
нужен для нативных модулей SQLite вне Expo Go новых версий).

### Голосовой ввод еды

Используется системная диктовка клавиатуры: нажми 🎙 на клавиатуре в поле «Добавить приём»,
продиктуй («съел тарелку гречки с курицей 200 г») и нажми «Спросить AI» — Claude разберёт
описание в КБЖУ.

## Схема БД (SQLite)

`exercises` · `workouts` · `sets` · `user_progress` (личные рекорды) · `nutrition_log` ·
`food_database` (1000+ позиций, сидируется при первом запуске). Настройки пользователя —
в AsyncStorage (`user_settings`). Программы тренировок — статические данные в `src/data/programs.ts`.
