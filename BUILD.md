# Установка FitTrack как отдельного приложения (иконка на телефоне)

Есть два пути получить иконку на домашнем экране. Рекомендуемый — **бесплатный PWA**.

---

## Путь 1 (рекомендуется). PWA — бесплатно, без App Store

Иконка на iPhone/Android, запуск на весь экран, офлайн, данные на устройстве —
**без аккаунта разработчика и без оплаты**.

```powershell
npm run build:web      # собирает PWA в папку dist/
```
Дальше выложи `dist/` на бесплатный HTTPS-хостинг и добавь ссылку на экран «Домой».
Полная пошаговая инструкция со скриншотами-описанием: **[QUICKSTART.md](./QUICKSTART.md)**.

Почему этого достаточно:
- всё приложение работает **локально** (тренировки, дневник, прогресс, КБЖУ, база продуктов);
- данные хранятся на телефоне (SQLite/OPFS) и сохраняются между запусками;
- никаких серверов, ключей и подписок.

---

## Путь 2 (опционально). Нативная сборка через App Store

Нужна, только если хочешь «настоящую» нативную сборку в App Store/Google Play.
Для iPhone требуется аккаунт **Apple Developer — 99 $/год** (требование Apple). Mac не нужен —
сборка идёт в облаке через EAS Build. Конфиг уже готов (`eas.json`, идентификаторы в `app.json`).

### iPhone (нужен аккаунт Apple Developer, 99 $/год)
```powershell
npm install -g eas-cli
eas login
eas init
eas build --platform ios --profile production
eas submit --platform ios --latest
```
Затем на айфоне установить **TestFlight** → принять приглашение → установить FitTrack.

### Android (бесплатно, без аккаунта)
```powershell
npm install -g eas-cli
eas login
eas init
eas build --platform android --profile preview
```
EAS вернёт ссылку на `.apk` — скачать на телефон и установить.

> Приложение полностью офлайн, поэтому при нативной сборке никакие адреса серверов
> или ключи прописывать не нужно — всё считается на устройстве.
