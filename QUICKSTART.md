# Быстрый старт на Windows

Пошаговая инструкция, как запустить GymAI на Windows и открыть на телефоне.

## Что понадобится

1. **Node.js 20+** — скачать с https://nodejs.org (кнопка LTS), установить «Далее-Далее».
   Проверка в PowerShell: `node -v` (должно показать v20 или выше).
2. **Телефон** с приложением **Expo Go** (App Store / Google Play).
3. **Ключ Anthropic** (`sk-ant-…`) — из https://console.anthropic.com → API Keys.
4. Телефон и компьютер — в **одной Wi-Fi сети**.

---

## Шаг 1. Скачать проект

Вариант А (git):
```powershell
git clone https://github.com/Ruslan77087/gym-ai-app.git
cd gym-ai-app
```
Вариант Б: распаковать `gym-ai-app-src.zip` и открыть папку в терминале.

---

## Шаг 2. Узнать IP компьютера

В PowerShell:
```powershell
ipconfig
```
Найди строку **IPv4-адрес** активного адаптера (Wi-Fi), например `192.168.1.42`.
Запомни — он нужен в шаге 4.

---

## Шаг 3. Запустить AI-сервер

Открой **первое** окно PowerShell в папке проекта:
```powershell
cd server
npm install
copy .env.example .env
notepad .env
```
В открывшемся блокноте впиши свой ключ вместо заглушки, сохрани (Ctrl+S), закрой:
```
ANTHROPIC_API_KEY=sk-ant-твой-настоящий-ключ
```
Запусти сервер:
```powershell
npm start
```
Должно появиться: `AI-сервер запущен: http://localhost:3000`.
Это окно **не закрывай** — сервер должен работать.

Проверка (в браузере): http://localhost:3000/health → `{"ok":true,...}`

---

## Шаг 4. Запустить приложение

Открой **второе** окно PowerShell в папке проекта (корень `gym-ai-app`):
```powershell
npm install
$env:EXPO_PUBLIC_API_URL = "http://192.168.1.42:3000"   # ← подставь свой IP из шага 2
npx expo start
```
> Важно: в `EXPO_PUBLIC_API_URL` именно IP из шага 2, а **не** `localhost` —
> телефон должен достучаться до компьютера по сети.

---

## Шаг 5. Открыть на телефоне

В терминале появится **QR-код**.
- **Android:** открой Expo Go → «Scan QR code» → наведи на QR.
- **iOS:** открой обычную Камеру → наведи на QR → нажми всплывающую ссылку.

Приложение откроется на экране онбординга (3 шага) — дальше всё внутри.

## Если что-то не так

**«expo-sqlite» ошибка в Expo Go.** В Expo SDK 56 нативный SQLite может не работать
в стандартном Expo Go. Решение — собрать dev-клиент один раз (нужен Android-эмулятор
или подключённый по USB телефон с включённой отладкой):
```powershell
npx expo run:android
```
Дальше запуск снова через `npx expo start`.

**Телефон не видит сервер (фото/чат не работают, тренировки работают).**
- Проверь, что в `EXPO_PUBLIC_API_URL` правильный IP (шаг 2), а не `localhost`.
- Телефон и ПК в одной Wi-Fi сети.
- Брандмауэр Windows может блокировать порт 3000 — при первом запуске Node
  разреши доступ в «Частных сетях», или временно отключи брандмауэр для проверки.

**`npx expo start` не находит телефон.** Запусти с туннелем:
```powershell
npx expo start --tunnel
```

**Сервер пишет «не задан ANTHROPIC_API_KEY».** Проверь, что файл `server/.env`
создан и в нём правильный ключ (шаг 3).
