# Установка FitTrack на iPhone как приложение (PWA)

Цель: иконка FitTrack на домашнем экране, запуск на весь экран без браузерной строки —
как обычное приложение, но **бесплатно и без App Store**. Данные хранятся на телефоне.

Идея простая: один раз собираем приложение в папку, выкладываем её на бесплатный
HTTPS-хостинг, открываем ссылку в Safari и добавляем на экран «Домой».

---

## Шаг 1. Собрать приложение

В PowerShell, в папке проекта:
```powershell
npm install
npm run build:web
```
Появится папка **`dist`** — это и есть готовое приложение (статические файлы).

> Что внутри: `index.html`, `manifest.json`, `sw.js` (офлайн), папка `icons`,
> папка `_expo` с кодом. Всё нужное уже на месте — править ничего не надо.

---

## Шаг 2. Выложить папку `dist` в интернет (HTTPS)

PWA на iPhone ставится только с **https**-адреса. Самый простой бесплатный способ —
**Netlify Drop**, без настройки и без оплаты:

1. Открой на компьютере https://app.netlify.com/drop
2. Перетащи туда **папку `dist`** целиком (мышкой из проводника).
3. Через ~20 секунд получишь ссылку вида `https://random-name-123.netlify.app`.
4. (Необязательно) Заведи бесплатный аккаунт Netlify, чтобы ссылка осталась навсегда
   и её можно было переименовать.

Альтернативы (тоже бесплатные, с HTTPS): **Cloudflare Pages**, **Vercel**, **GitHub Pages**.
Принцип тот же — залить содержимое `dist`.

> Проверка с компьютера: открой полученную ссылку в браузере — должен загрузиться
> экран онбординга FitTrack.

---

## Шаг 3. Поставить иконку на iPhone

1. Открой полученную ссылку в **Safari** на айфоне (именно Safari, не Chrome).
2. Нажми кнопку **«Поделиться»** (квадрат со стрелкой вверх).
3. Выбери **«На экран Домой»** → **«Добавить»**.
4. На домашнем экране появится иконка **FitTrack** (гантель на тёмном фоне).
5. Запусти по иконке — приложение откроется **на весь экран, без адресной строки**.

---

## Что работает и где живут данные

- **Всё работает офлайн.** После первого открытия service worker кеширует приложение —
  иконка запускается даже без интернета.
- **Данные (тренировки, дневник, КБЖУ, рекорды) хранятся на самом телефоне**
  (SQLite/OPFS внутри приложения) и сохраняются между запусками. Сервер не нужен,
  никаких подписок и ключей.
- Платных API в приложении нет — расчёт КБЖУ и прогрессия весов считаются формулами
  локально.

---

## Обновить приложение позже

Внёс изменения в код — пересобери и перезалей:
```powershell
npm run build:web
```
и снова перетащи папку `dist` на хостинг (на Netlify Drop — новая загрузка поверх старой).
На телефоне обновление подхватится при следующем открытии (service worker сам обновит кеш).

---

## Если что-то не так

**Иконки «На экран Домой» нет / открывается с адресной строкой.**
Открывай ссылку именно в **Safari** (на iOS PWA ставится только через него).
Проверь, что адрес начинается с `https://`.

**Открылось, но пустой экран.**
Проверь, что заливал **содержимое/папку `dist`** целиком (вместе с `_expo`, `icons`,
`manifest.json`, `sw.js`), а не один `index.html`.

**Старая версия после обновления.**
Закрой приложение из списка запущенных и открой снова — service worker обновит кеш.
Либо удали иконку и добавь ссылку заново.

## Альтернатива для разработки — Expo Go

Чтобы просто потыкать приложение без выкладывания в интернет:
```powershell
npx expo start
```
и сканируй QR-код приложением Expo Go. Это режим разработки (нужен запущенный
компьютер), иконки на экране «Домой» он не даёт — для иконки используй PWA выше.
